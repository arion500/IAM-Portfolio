Project 1  VTV Recruiting Microsoft Entra ID Lab

Objective

Build a Microsoft Entra ID environment for a fictional football recruiting company to practice Identity and Access Management tasks.

Environment

Microsoft 365 E5 Trial

Microsoft Entra ID

Microsoft 365 Admin Center

Skills Practiced

Creating Users
Assigning Licenses
Creating Security Groups
Microsoft 365 Groups
Administrative Roles
 RBAC
 MFA
 Conditional Access

Business Scenario

VTV Recruiting is a football recruiting company.

Employees require different permissions based on their departments.

Departments include:

 Recruiting
 Finance
 HR
 Marketing

Each employee receives only the permissions required to perform their job.
